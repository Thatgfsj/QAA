# 工作区浏览

用户要求「看看这里有什么」「梳理目录」「这个文件是做什么的」时使用本技能。

## 步骤

1. 用 read 读取当前目录：`read({"path": "."})`，得到目录 / 文件清单与文件大小。
2. 挑选 2-4 个关键文件（README、构建脚本、入口文件、配置）逐个读取；长文件只读开头，不重复读同一文件。
3. 最多向下展开两层目录，不要遍历整个工作区。
4. 用中文输出：
   - 目录结构（缩进列表，只列有意义的目录与文件）
   - 关键内容摘要（每条注明路径，1-2 句）
   - 下一步建议（需要改哪里、还缺什么）

## 注意

- 只读探查阶段不要调用 write / edit；写入类工具会先请求用户确认。
- read 提示「二进制文件」时跳过，并在概览中说明。
- 路径一律用沙盒相对路径，不使用绝对路径或 `..`。
