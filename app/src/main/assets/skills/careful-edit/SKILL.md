# 文件小步修改

用户要求「改一下这个文件」「修个 bug」「更新文档」时使用本技能。

## 步骤

1. 先用 read 读取目标文件（以及相关调用方），确认当前内容与上下文。
2. 只改必须改的部分：优先用 edit 做最小替换，整文件重写仅在需要大改时使用 write。
3. 动手前用一句话说明：改哪个文件、改什么、为什么；写入类工具会先请求用户确认。
4. 修改后用 read 复查结果，确认没有破坏引号、缩进与编码。
5. 用中文汇报：文件路径、改动要点、未覆盖的风险。

## 注意

- 不要顺手改无关代码；发现别的问题只记录并告知用户。
- 路径一律用沙盒相对路径，不要写入沙盒之外的目录。
- 优先可回滚的小步改动，不追求一次到位。
